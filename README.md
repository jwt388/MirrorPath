# Mirror PathPlanner Paths and Autos

Python program to mirror PathPlanner paths left-to-right from drive team perspective 
across the field's centre line. Complete autonomous routines can also be mirrored with 
all of the path files mirrored. The keywords "left" and "right" are used to identify the
side of the input files and the terms are reversed in the output.

## Programs:
- mirror_path.py - command line program to mirror a path file
- mirror_auto.py - command line program to mirror an autonomous routine file and all paths in the autonomous
- automirror.py - GUI program to select and mirror a path file or autonomous routine file

Requires Python 3 but no 3rd party libraries are used.
